# Java 03 - Raporti i sotëm

Data: 2026-10-05

## Përmbledhje
U krijua struktura bazë e repository-s, u vendosën skedarët e nevojshëm dhe u verifikuar lidhjet me Git.

## Pika kryesore
- Repository ka qenë i konfiguruar dhe lidhur me remote `origin`.
- U mbajt struktura e përshkruar sipas kërkesës.
- Aplikacioni është organizuar në dosjen `aplikacioni/`.

## Ndërtimi i projektit
- Terminali duhet të hapet në dosjen `rideshare-mobile/aplikacioni`.
- Repozit kryesor mbetet në nivelin `rideshare-mobile/`.

## Përfundim
Projekti është i gatshëm për të vazhduar zhvillimin dhe versionimin me Git.
